# Captive-portal-using-ESP8266
ESP8266 Captive Portal with LittleFS  A learning project built with an ESP8266 NodeMCU to explore Wi-Fi networking and network configuration on microcontrollers.  The ESP8266 is configured as a Wi-Fi Access Point with a custom SSID. When a device connects, a DNS-based captive portal redirects the device to a locally hosted web page.
